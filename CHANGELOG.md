# MiraQlum Operator — Public changelog

This changelog documents **verified user-facing milestones**, not internal source commits, unpublished security details, infrastructure topology or proprietary hosted-service implementation.

**Release convention:** hosted-service updates and WordPress Connector versions are separate; a service update does **not** imply a new plugin ZIP or public WordPress.org release. Dates refer to verified internal owner-operated milestones, not general availability.

## 2026-10-27 — WordPress-native navigation and bilingual website progress

**Owner-operated product work — not a public plugin release**

### Demonstrated
- WordPress-native main and footer menu workflows, including menu items and registered theme menu-location assignment, using the existing MiraQlum connection and approved execution path.
- English/Hungarian product pages and a static English homepage on the Operator website; full-width page-template work in its proven scope.
- Existing, supported Yoast SEO data access and focused metadata editing. Broader SEO compatibility and public indexing remain separately scoped.

**Evidence boundary:** the native menu data and its assignment were verified in the owner-operated site; that is not a blanket cross-theme, cross-host or full mobile-visual guarantee. The legal-document site integration remains in preparation.

## 2026-10-26 — Free-policy adjustment, native appearance and maintenance

**Owner-operated DEV/PROD — hosted service and connected WordPress**

### Improved
- Free daily usage policy and basic no-charge account/discovery/planning controls; **current allowance values are maintained on the [official Plans page](https://operator.miraqlum.com/plans/)**.
- Supported native global theme appearance, including demonstrated color and typography changes.
- Generic plugin/theme lifecycle and approved multi-plugin maintenance with individual result records and postcondition readback.
- Durable recovery and consistent reporting of partial results, without retroactively rewriting failed receipts as successful.

**Evidence boundary:** an eventually converged WordPress state does not change the historical outcome of a failed immediate update attempt. These milestones do not establish a public WordPress.org release.

## 2026-10-25 — Free usage, Welcome and customer-facing usage experience

**Hosted service — owner-operated DEV/PROD**

### Added
- Daily Free allowance and account-wide usage status (historical initial configuration; subsequently adjusted on 26 October).
- A Welcome experience that starts on the first eligible verified WordPress site pairing.
- Optional account-bound monthly bonuses, each requiring explicit activation; non-rollover monthly expiry.
- Human-readable available balance, reset/expiry times, and connected-site usage summaries.
- Contextual usage-threshold information for AI clients, with text fallback.

### Improved
- Replay-aware accounting for authorized WordPress work; internal retries of the same accepted operation do not independently deduct usage.
- Continued progress of previously accepted jobs through quota or time boundaries.

**Availability note:** verified in owner-controlled environments; independent new-account public onboarding remains in validation. This is **not a general paid-tier release**.

**Availability note:** the installed build identified in this historical milestone was **not** a downloadable GitHub or WordPress.org public release. The hosted service has its own release versions.
