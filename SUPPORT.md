# Support & contact

**Product:** MiraQlum Operator — AI-powered WordPress workflows through the Model Context Protocol (MCP).

**Email:** [support@operator.miraqlum.com](mailto:support@operator.miraqlum.com)  
**Product site:** [operator.miraqlum.com](https://operator.miraqlum.com/)

## Before asking for help

Please include:
- What you intended to do, in everyday language.
- The WordPress/editor/plugin combination involved, if relevant.
- Whether this was a read-only inspection or a proposed authorized change.
- The outcome shown by the MiraQlum assistant, with credentials and site-sensitive details redacted.
- A date/time and any non-sensitive error message.

**Never post passwords, access tokens, private URLs, account IDs, customer records or full WordPress content in public issues.**

## Can I open a public issue?

Yes, for non-sensitive documentation feedback or reproducible public-facing bugs. Please [open an issue](https://github.com/miraqlum/miraqlum/issues) without sensitive environment details. A public GitHub issue is not a private customer support ticket or a guaranteed SLA channel.

For account-specific help or possible vulnerabilities, use email.
