# Contributing to MiraQlum public documentation

Thanks for helping make MCP-connected WordPress work more understandable.

This repository currently holds **public project/profile documentation**, not the hosted-service implementation or the full WordPress Connector source. Please keep issues and contributions focused on documentation quality, clarity, accessibility, accurate technical terminology, and reproducing **publicly shareable** user-facing observations.

## Before a contribution

1. Read [the product overview](docs/overview.md) and [current release status](docs/wordpress-connector.md).
2. Propose the smallest useful change, based on publicly verifiable facts.
3. Do not post private accounts, customer data, credentials, unreleased source, internal endpoints, deployment details, or security exploit information.
4. Report suspected vulnerabilities privately through [SECURITY.md](SECURITY.md).

Documentation improvements are welcome. Contributions do not confer permission to modify third-party WordPress installations.

**Licensing note:** this documentation-only profile repository should not be interpreted as the open-source license or release distribution for the separate WordPress Connector. That plugin's actual package, dependencies and licensing are reviewed for its release.
